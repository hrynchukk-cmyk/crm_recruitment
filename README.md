# CRM рекрутингу

Внутрішня CRM для команди рекрутерів, яка закриває вакансії підприємств Львова (здебільшого лінійні посади).

**Головний сценарій:** рекрутер відкриває вакансію, бачить усіх кандидатів на неї і веде кожного по статусах: від «Новий» до «Вийшов на роботу» або «Відмова».

## Що вміє зараз

- **Вакансії.** Список вакансій по підприємствах. Для кожної видно, скільки нових кандидатів, скільки в роботі і скільки вже вийшло на роботу з потрібної кількості. Є фільтри «Відкриті / На паузі / Закриті» та «Лише мої».
- **Кандидати на вакансії.** Вкладки за статусами з лічильниками і пошук за ім'ям або телефоном. Статус змінюється прямо в таблиці через випадний список. Телефон клікабельний, тож з мобільного можна одразу подзвонити.
- **Картка кандидата.** Тут контакти, резюме, супровідний лист, дата співбесіди, нотатки й повна історія змін (хто, коли і на який статус змінив). Також видно, на які ще вакансії подавався цей кандидат.
- **Без дублікатів.** Кандидат з тим самим телефоном (у будь-якому форматі: `067…`, `+38 (067)…`) або email не створюється вдруге, а додається на нову вакансію як уже наявний.
- **Адмінка** (`/admin/`). Тут ведуть підприємства-замовники й користувачів (рекрутерів).

### Статуси

| В роботі | Закриті |
|---|---|
| Новий | Вийшов на роботу |
| Не додзвонилися | Резерв |
| Зв'язалися | Відмова: не підходить |
| Співбесіда призначена | Відмова: кандидат відмовився |
| Передано підприємству | |
| Пропозиція / погодили | |

Статуси задані в `recruiting/models.py` (`Application.Stage`) і легко змінюються під ваш процес.

## Інтеграція з Work.ua

**Стан:** логіка синхронізації готова й покрита тестами. Не вистачає лише доступу до API Work.ua.

У Work.ua **немає публічного документованого API** для роботодавців. ATS-системи (PeopleForce, HURMA та інші) отримують відгуки через партнерський доступ, який надає сам Work.ua. Що потрібно зробити:

1. Звернутися до Work.ua (менеджер облікового запису роботодавця або підтримка). Запитати доступ до API для отримання відгуків на свої вакансії для власної CRM і документацію до нього.
2. Після отримання доступу реалізувати `WorkUaApiClient.list_responses()` у `recruiting/integrations/workua.py`. Це лише перетворення відповіді API на `WorkUaResponse`. Решта (дедуплікація, створення кандидатів, історія) вже працює.
3. Задати змінні `WORKUA_BACKEND=api`, `WORKUA_API_BASE_URL`, `WORKUA_LOGIN`, `WORKUA_PASSWORD`.

Як це працюватиме:

- У вакансії вказується її ID або посилання на Work.ua (`https://www.work.ua/jobs/1234567/`).
- Кнопка «⟳ Відгуки з Work.ua» на сторінці вакансії підтягує нові відгуки.
- Для автоматичної синхронізації команду `python manage.py sync_workua` ставлять у cron, наприклад раз на 15–30 хвилин.

**Поки доступу немає,** кандидатів додають кнопкою «+ Кандидат» на сторінці вакансії і вставляють посилання на резюме з Work.ua.

## Технології

Python 3.13, Django 5.2, PostgreSQL (у продакшні) або SQLite (локально), серверні шаблони без JS-фреймворків. Інтерфейс українською, часовий пояс — Київ.

## Локальний запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
export DJANGO_DEBUG=1
.venv/bin/python manage.py migrate
.venv/bin/python manage.py seed_demo   # демо-дані + користувач admin/admin
.venv/bin/python manage.py runserver
```

Відкрийте http://127.0.0.1:8000.

Тести:

```bash
DJANGO_DEBUG=1 .venv/bin/python manage.py test
```

## Розгортання (Docker)

```bash
cp .env.example .env   # заповніть секрети, домен, паролі
docker compose up -d --build
docker compose exec web python manage.py createsuperuser
```

Застосунок слухає порт 8000. Перед ним варто поставити HTTPS-проксі (Caddy, Nginx або хостинг з TLS) і вказати домен у `DJANGO_ALLOWED_HOSTS` та `DJANGO_CSRF_TRUSTED_ORIGINS`.

## Структура

```
config/                      налаштування Django
recruiting/models.py         підприємства, вакансії, кандидати, статуси, історія
recruiting/services.py       зміна статусу, нотатки, додавання кандидата (з дедуплікацією)
recruiting/integrations/     інтеграція з Work.ua
recruiting/views.py          сторінки рекрутера
recruiting/management/       команди sync_workua і seed_demo
```
